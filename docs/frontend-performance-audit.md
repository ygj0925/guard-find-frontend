# 前端性能审查与优化

审查日期：2026-11-02。基线版本：`0a766f3384824bf785ae9e857e9cb045a8aa5973`。

覆盖 `src/pages` 下全部 36 个页面入口及相关弹窗、表单、布局、权限组件、Umi 模型与资源入口。第二轮复核从弹窗扩展到页面加载、字典订阅、未读数共享、主表格 DOM 和标签页内存。按 `vercel-react-best-practices` 的状态订阅、减少渲染、按需加载、虚拟化和批量布局读写原则实施；保留 Umi / Ant Design 架构。

## 已定位的原因与修改

| 原因 | 影响 | 已实施修改 |
| --- | --- | --- |
| 弹窗可见性、当前记录保存在列表页面的 state 中 | 每次打开或关闭都会重新执行页面组件，重新创建列、操作按钮及表格子树；数据越多越明显 | 新增 `DialogHost` 与 `useDialog`，只有弹窗宿主订阅状态；迁移管理列表和消息列表的相关弹窗，保留操作成功后的列表刷新 |
| 隐藏弹窗及表单过早挂载，打开时又调用 `resetFields` / `setFieldsValue` | 额外表单重建、控件初始化和异步选项请求 | 首次打开才挂载；每次打开创建新的表单实例；10 个表单组件改用合并默认值和当前记录的 `initialValues` |
| 公告编辑、预览先等待详情请求，再设置弹窗可见 | 网络耗时直接成为“点击没反应”的时间 | 先显示弹窗和加载状态，再请求详情；忽略关闭或切换后的迟到响应；加载失败显示错误且禁止误提交 |
| 组织树、角色权限树、套餐权限树缺少固定视口 | 大量节点同时生成 DOM、布局和事件处理器 | 给树设置固定高度并启用虚拟滚动；异步树有数据后才挂载，保留默认展开行为 |
| 代码生成器字段配置每次修改重建全部单元格，且原逻辑会修改行对象 | 输入和勾选会触发整个编辑表格的渲染 | 不可变更新、稳定回调、缓存列定义、`shouldCellUpdate` 和表格虚拟滚动 |
| 富文本、裁剪、颜色选择依赖随页面加载；图标选择器关闭时仍准备所有分类元素 | 增加页面加载、组件初始化和弹窗首次渲染工作 | 富文本、裁剪、调色板使用 `React.lazy` / `Suspense`；裁剪在选图后加载；图标仅在打开后生成当前分类，同时消除循环导入 |
| 表格大量权限按钮重复建立权限查询结构并订阅整个初始状态 | 放大行渲染开销，无关状态变化也影响权限按钮 | 按用户对象缓存权限检查器，用 Set 查询权限/角色，只订阅当前用户 |
| 布局依赖范围过大及重复计算、DOM 读写交错 | 无关状态变化重复查未读数，标签栏测量可能强制同步布局 | 缩小请求依赖、忽略过期结果、缓存授权键，先读完布局再写 CSS 变量 |
| 分析页每一行重复遍历全量时段数据求最大值 | 相关计算为 O(n²) | 一次 `reduce` 后缓存最大值，降为 O(n) |

### 弹窗生命周期约定

`useDialog` 控制器在页面生命周期内保持稳定，只有 `DialogHost` 使用 `useSyncExternalStore` 订阅。未打开过的弹窗不挂载；调用 `open(data)` 时递增实例键，避免编辑不同记录或再次新增时保留上次草稿。关闭时保留内容和数据供退出动画使用，内部 Modal / Drawer 的 `destroyOnHidden` 负责隐藏后的内容销毁；再次打开会创建新实例。不要把需要跨次打开保留的业务状态放进这种表单实例中。

字典请求说明：后端仍按编码提供接口，`dict.dictData(codes)` 内部也是逐编码并发请求。本轮没有声称将不同编码合并成一个 HTTP 请求；重点是按编码去重、限制通知范围、隔离错误。缓存随用户/租户作用域重建，不跨账号共享。`useDictContext` 的完整接口保留给需要观察全部字典的调用方，常规控件改用编码级订阅。

资源检查脚本 `scripts/check-production-bundle.cjs` 只读取本次 `dist/index.html` 引用的入口文件，输出原始字节、gzip 字节和 source map 中的依赖。它不会把目录里的旧 chunk / HMR 文件算进首屏体积，也不会把本地 gzip 大小当成服务器已启用压缩的证据。运行：`node scripts/check-production-bundle.cjs [构建目录]`。

最终 `zy` 构建入口 `umi.93ea2350.js` 为 1,427,757 字节，本地 gzip 为 456,667 字节；另有 `scripts/loading.js` 5,460 字节，gzip 为 1,299 字节。入口 source map 未包含 wangeditor、react-cropper、react-color。这轮主要收益来自交互渲染、订阅隔离和 DOM 数量控制，没有将其描述为入口包体积大幅缩减；React / Ant Design / Umi 等公共依赖仍占入口的主要部分。
